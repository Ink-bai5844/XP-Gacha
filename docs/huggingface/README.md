## 项目简介

本仓库提供 [XP-Gacha](https://github.com/Ink-bai5844/XP-Gacha) 配套的数据导入包，用于本地目录管理、元数据检索、标签处理及推荐功能测试。

数据由 NH / JM 来源的作品条目信息整理而成，包含标题、标签、作者、链接等元数据，以及标签和标题词处理词典。收录条目不代表对作品内容、来源站点或相关观点的认可。

**本说明对应的 `input_data.zip` 不包含漫画正文、封面或缩略图。** 外部链接指向的内容不属于本数据包；访问外部站点仍须遵守其访问规则、年龄限制及适用法律。

## 文件内容

下载文件为 `input_data.zip`；如同时提供 `input_data.zip.sha256`，可用于校验压缩包完整性。上述版本的包内文件如下：

| 文件 | 说明 |
| --- | --- |
| `gallery_info_full.csv` | UTF-8 BOM 编码的条目元数据表 |
| `SEMANTIC_MAP.json` | 标签语义映射，2,887 项 |
| `STOP_TAGS.txt` | 标签过滤词，190 项 |
| `TITLE_SEMANTIC_MAP.json` | 标题词语义映射，97 项 |
| `TITLE_STOP_WORDS.txt` | 标题停用词，307 项 |
| `README.txt` | 数据包版本与导入说明 |
| `manifest.json` | 字段、统计、成员文件大小及 SHA-256 |

CSV 包含 11 列：

```text
ID,链接,文件名,标题,标题译文,标签,作者,团队,语言,页数,上传日期
```

`文件名` 是可选的本地目录匹配信息，不表示包中附带对应作品文件。`上传日期` 是采集到的来源字段，不应视为经过核验的作品创作或首次出版日期。

这里的四份词典是本数据包的**完整版词典**，不是源码仓库中的 `_empty` 空模板。映射与过滤规则可能带有整理者的分类取舍，不应视为通用、权威或无偏的分类标准。

## 导入方式

1. 安装并启动 XP-Gacha，先备份目标数据库及自定义词典。
2. 打开“附录 → 一键导入词典 / 数据”，选择 `input_data.zip`。
3. 通常选择“增量写入 / 更新”。该模式可能更新已有 ID 的记录，并非只新增；不要误选“覆盖重建”。
4. 导入前确认是否需要使用包内词典。**导入这些词典会替换目标的同名词典，程序会备份旧词典。** 若要保留自己的词典，可解压后仅导入 `gallery_info_full.csv`。

数据包不附带应用程序、数据库连接配置、账户密钥、历史偏好缓存、向量索引或模型。使用前仍应自行检查下载来源、文件内容及适用范围。
